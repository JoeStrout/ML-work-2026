# rl_connect4

Connect-4 RL in PyTorch: a DQN line of work, then an AlphaZero rewrite that
beat every DQN checkpoint. See `RECAP.md` for the chronology and results.

## Layout

Shared:

- `connect4/env.py` — Connect-4 game rules and 2-channel observation.
- `connect4/opponents.py` — random and one-ply (win/block) opponents.
- `play.py` — interactive play against any opponent.
- `eval.py` — win-rate evaluation, including head-to-head between checkpoints.

DQN:

- `connect4/network.py` — 4-layer conv Q-net (128 channels, 256-unit head).
- `connect4/replay.py` — uniform replay buffer (stores per-transition n-step discounts).
- `connect4/agent.py` — DQN agent (double-DQN, target net, ε-greedy or Boltzmann).
- `connect4/selfplay.py` — snapshot pool + network opponent.
- `connect4/config.py` — DQN hyperparameters.
- `train.py` — DQN training loop.

AlphaZero:

- `connect4/az_network.py` — policy+value net (4 residual blocks, 128 channels).
- `connect4/mcts.py` — PUCT MCTS with Dirichlet root noise.
- `connect4/az_agent.py` — MCTS-driven greedy player.
- `az_train.py` — self-play training loop (hyperparameters in `AZConfig`).

## Play

Defaults to the AlphaZero net at 100 sims/move:

```bash
python play.py                                       # you are X, AZ is O
python play.py --as O --az-sims 400                  # AZ opens, thinks harder
python play.py --opponent oneply                     # the heuristic baseline
python play.py --opponent dqn --ckpt checkpoints/dqn_selfplay.pt
```

## Train

AlphaZero (the run in `RECAP.md` was ~1 hour on an RTX 4090):

```bash
python az_train.py --iterations 100 --games-per-iter 25 --sims 100 \
    --ckpt checkpoints/az.pt
```

DQN, with a curriculum from random to the 1-ply opponent to self-play:

```bash
python train.py --opponent random --total-steps 300000 --ckpt checkpoints/dqn_random.pt
python train.py --opponent oneply --total-steps 500000 \
    --ckpt checkpoints/dqn_oneply.pt --resume checkpoints/dqn_random.pt
python train.py --opponent selfplay --total-steps 1000000 \
    --ckpt checkpoints/dqn_selfplay.pt --resume checkpoints/dqn_oneply.pt
```

Self-play mixes 20% random / 20% oneply / 60% snapshot-pool opponents per
episode and pins the warm-start weights into the pool as a permanent anchor;
without that anchoring it drifts badly (see `RECAP.md` §5).

Exploration is Boltzmann sampling over legal moves at `Config.temperature`
(default 0.1). While that is above zero the ε-greedy schedule is bypassed
entirely, so `--eps-start` / `--eps-decay-steps` only take effect if you also
set `temperature = 0.0` in `connect4/config.py`. The `--resume` flag drops the
default `eps_start` from 1.0 to 0.3 for the same reason it was added — so
pre-trained weights aren't washed out by exploration.

## Evaluate

```bash
python eval.py --az --ckpt checkpoints/az.pt --opponent oneply --games 200
python eval.py --ckpt checkpoints/dqn_selfplay.pt --opponent random --games 500
```

Head-to-head between two checkpoints (`--opponent ckpt` for a DQN opponent,
`--opponent az` for an AlphaZero one):

```bash
python eval.py --az --ckpt checkpoints/az.pt \
    --opponent ckpt --vs-ckpt checkpoints/dqn_selfplay.pt --games 100
```

Games alternate who moves first. Both sides act at `--temperature` (default
0.1) for the DQN nets; AlphaZero players are always MCTS-greedy at
`--az-sims`. Use enough games that you are not just replaying one deterministic
line — argmax play at `--temperature 0` collapses to two distinct games.

## Reward convention (DQN)

Transitions are stored from the learner's perspective. Each stored
transition covers *one full round*: the learner's move plus the
opponent's reply. Reward is `+1` if the learner won, `-1` if the
opponent won on the reply, `0` otherwise. The bootstrap target uses
the learner's next Q-values on their next turn, so no sign flipping is
needed at learn time.

## Checkpoints

`checkpoints/` is gitignored — weights are regenerated by the commands above.
The trained artifacts from the `RECAP.md` runs were `az.pt` (best overall),
`dqn_random.pt`, `dqn_oneply.pt`, `dqn_selfplay.pt` (best DQN), and
`dqn_selfplay_t.pt`.
